# Room 02 equipment models

Place optional local GLB/GLTF replacements for the Room 02 registry entries in this folder. The scene keeps a procedural fallback until an entry in `app/equipmentRegistry.ts` points at a model here.

Suggested filenames:

- `wave-apparatus.glb`
- `sound-apparatus.glb`
- `electrostatics-bench.glb`

Keep model origins at the table mount and use metres for dimensions. Named attachment points should match the registry anchors when a custom model is introduced.
