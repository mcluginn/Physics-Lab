# Physics laboratory asset library

This folder keeps the new virtual laboratory's visual resources organized by purpose.

- `transverse_waves/`, `sound_waves/`, and `electrostatics/` contain topic-specific station artwork.
- `environment/`, `furniture/`, `props/`, and `textures/` contain reusable laboratory scene resources copied from the local reference project.
- `placards/` contains station-facing visual cards.
- `references/` contains clean visual-reference copies for lesson planning and future editing.

The original reference asset library and lesson presentations are not modified.
