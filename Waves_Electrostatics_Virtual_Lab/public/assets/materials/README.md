# Room 02 PBR materials

Optional texture maps can be added here without changing scene code. Custom GLB/GLTF assets may reference these paths through `materialOverrides` in `app/equipmentRegistry.ts`.

Supported map slots are `map`, `normalMap`, `roughnessMap`, `metalnessMap`, `aoMap`, and `emissiveMap`. Use matching local files for a named material, for example `wave-metal-normal.jpg` or `sound-glass-roughness.jpg`.
